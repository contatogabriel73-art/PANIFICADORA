# Maison Dourada Padaria e Café

Site institucional demo de uma padaria e confeitaria fictícia em Joinville/SC. Projeto de portfólio.

## Seções
- Hero com vídeo de fundo
- Buffet de café
- Cardápio de cafés
- Reserva de mesa (envia para o WhatsApp)
- Eventos
- Nossa história
- Galeria do espaço
- Horários e localização
- Encomendas
- Botão flutuante de WhatsApp

## Identidade
Preto, dourado e creme. Elegante, premium e artesanal.

## Como trocar a identidade
Todos os dados da marca (nome, logo, cores, textos, horários, preços, telefone, Instagram e endereço) ficam em um único arquivo de configuração. Para adaptar o site a outro cliente, edite só esse arquivo e substitua o logo, o vídeo e as fotos.
